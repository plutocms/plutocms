`@plutocms/ui` is a layer with shared Vue components. The shop and blog layers extend it.

## PostTitleInput

`PostTitleInput` is a controlled input for post and article titles.

```vue
<PostTitleInput v-model="title" placeholder="Add title" />
```

| Prop | Default | Meaning |
| --- | --- | --- |
| `placeholder` | `'Add title'` | The placeholder text |

- Bind a string with `v-model`.
- The input has large text (`text-4xl font-bold`), padding, and no outline.
- An edit icon shows on the right. It fades out when the input has focus.
- The component sets `inheritAttrs: false` and forwards unregistered attributes to the input.
- The `v-autofocus` directive gives the input focus when the component mounts.

## Tailwind

This package ships no Tailwind entry and registers no `css` option. The app owns the only Tailwind build. Nuxt UI adds a source for the `app/` directory of every layer, so the classes of this package are generated by the build of the app.

Do not add a Tailwind import to this package. A second build in a page overrides the utilities of the first.

If the package needs its own tokens, put them in `app/assets/css/pluto-layer.css`. Do not import Tailwind there. See [Styles](/core/styles).
