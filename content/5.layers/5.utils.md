`@plutocms/utils` has shared utilities and composables for Pluto layers. Other layers extend it.

## Format a currency

```ts
formatCurrency(value: number, options?: Options): string
```

The function supports three currencies:

| Code | Locale | Symbol |
| --- | --- | --- |
| `USD` | `en-US` | `$` |
| `BRL` | `pt-BR` | `R$` |
| `CAD` | `en-CA` | `$` |

| Option | Default | Meaning |
| --- | --- | --- |
| `currency` | `'USD'` | The currency code |
| `spaceBetween` | `true` | A space between the symbol and the number |
| `prefix` | `'symbol'` | `'symbol'` or `'code'` |
| `trailingZero` | `true` | Always show two decimals. When `false`, a whole amount shows no decimals. |

```ts
formatCurrency(1000) // '$ 1,000.00'
formatCurrency(1000, { currency: 'BRL' }) // 'R$ 1.000,00'
formatCurrency(1000, { spaceBetween: false }) // '$1,000.00'
formatCurrency(1000, { trailingZero: false }) // '$ 1,000'
formatCurrency(1000, { prefix: 'code' }) // 'USD 1,000.00'
```

The function uses `Intl.NumberFormat`, so the symbol, the decimal mark, and the thousands mark follow the locale.

## String helpers

| Function | Use |
| --- | --- |
| `slugify(text)` | Makes a URL-safe slug. It removes accents and converts to kebab-case. `"Café au Lait"` becomes `"cafe-au-lait"`. |
| `fileNameToKebabCase(name)` | Converts a file name to kebab-case and keeps the extension. `"My Document.pdf"` becomes `"my-document.pdf"`. |
| `domainFromUrl(url)` | Gets the domain. It ignores the protocol and `www.`. `"https://www.example.com/path"` becomes `"example.com"`. It returns `undefined` for `null`, `undefined`, or an empty string. |

::note
Core also has `slugifyTitle`. Do not name a helper `slugify` in a layer: `@plutocms/utils` already auto-imports that name.
::

## Admin navigation (legacy)

Three composables predate the [extension registry](/core/extension-registry). They still work through a compatibility bridge. Use `definePlutoExtension` in new code.

| Composable | Use |
| --- | --- |
| `useNavbarAdmin()` | `registerNavbar(component)` registers the admin navbar. |
| `useNavbarAdminActions()` | `addAction(component)` adds an action button to the navbar. |
| `useSidebarAdminActions()` | `addAction(items)` adds menu items to the sidebar. It skips an item whose `label` already exists. |

`NavbarAdminActionButton` is a standard button for navbar actions. It has the props `label`, `icon`, `to`, `show`, `title`, `disabled`, and `target`. Under 64rem, it hides the label and shows the icon only.
