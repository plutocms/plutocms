`@plutocms/utils` has shared utilities for Pluto layers. The other layers extend it.

An app does not add this layer to `extends`. `@plutocms/pluto` already extends it, so every app that uses a Pluto layer has these helpers. See [Layers](/core/layers).

## Format a currency

```ts
formatCurrency(value: number, options?: Options): string
```

The function supports three currencies:

| Code | Locale | Symbol |
| --- | --- | --- |
| `USD` | `en-US` | `$` |
| `BRL` | `pt-BR` | `R$` |
| `CAD` | `en-CA` | `$` |

| Option | Default | Meaning |
| --- | --- | --- |
| `currency` | `'USD'` | The currency code |
| `spaceBetween` | `true` | A space between the symbol and the number |
| `prefix` | `'symbol'` | The `currencyDisplay` of `Intl.NumberFormat`: `'symbol'`, `'code'`, `'name'`, or `'narrowSymbol'` |
| `trailingZero` | `true` | Always show two decimals. When `false`, a whole amount shows no decimals. |

```ts
formatCurrency(1000) // '$ 1,000.00'
formatCurrency(1000, { currency: 'BRL' }) // 'R$ 1.000,00'
formatCurrency(1000, { spaceBetween: false }) // '$1,000.00'
formatCurrency(1000, { trailingZero: false }) // '$ 1,000'
formatCurrency(1000, { prefix: 'code' }) // 'USD 1,000.00'
```

The function uses `Intl.NumberFormat`, so the symbol, the decimal mark, and the thousands mark follow the locale.

## String helpers

| Function | Use |
| --- | --- |
| `slugify(text)` | Makes a URL-safe slug. It removes accents and converts to kebab-case. `"Café au Lait"` becomes `"cafe-au-lait"`. |
| `fileNameToKebabCase(name)` | Converts a file name to kebab-case, encodes the name part with `encodeURIComponent`, and keeps the extension. `"My Document.pdf"` becomes `"my-document.pdf"`. |
| `domainFromUrl(url)` | Gets the domain. It ignores the protocol and `www.`. `"https://www.example.com/path"` becomes `"example.com"`. It returns `undefined` for `null`, `undefined`, or an empty string. |

::note
Core also has `slugifyTitle`. Do not name a helper `slugify` in a layer: `@plutocms/utils` already auto-imports that name.
::
