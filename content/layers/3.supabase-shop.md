The shop layer adds products to the Pluto admin, and gives a storefront the data it needs.

## What it adds

- **Product admin**: list, create, edit, and delete products, with price, stock, made-to-order items, categories, and availability.
- **Photos**: the files of a product come from the media library of core.
- **Public data**: the published products on the public API, with their files, category, and availability.
- **Helpers**: `formatProductPrice` and the types of a public product.

## Install

Install the package first, with the command at the top of this page. `extends` does not install it.

Then extend it:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  extends: ['@plutocms/supabase-shop']
})
```

The layer brings `@plutocms/supabase` (and with it core). Your app extends only this layer. The shop template of `create-pluto` starts with it.

::tip
Add the [3D add-on](/layers/3d) to give a product a 3D model. The shop layer does not include it.
::
