The blog layer stores posts in Supabase. Editors write them in the Pluto admin.

## What it adds

- **Post admin**: list, create, edit, and delete posts.
- **The post editor**: a rich text editor that stores Markdown, a Markdown mode with a live preview of the site, an outline of the headings, and draft and publish controls.
- **Images**: a cover image, and images in the body, from the media library.
- **Capabilities**: `posts:read_drafts`, `posts:publish`, and `posts:delete`.
- **Public data**: the published posts on the public API, with an excerpt for each list item.
- **`PlutoProse`**: shows a stored post body as safe, styled HTML on your site.

## Install

Install the package first, with the command at the top of this page. `extends` does not install it.

Then extend it:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  extends: ['@plutocms/supabase-blog']
})
```

The layer brings `@plutocms/supabase` (and with it core). The blog template of `create-pluto` uses it when you pick the Supabase backend.
