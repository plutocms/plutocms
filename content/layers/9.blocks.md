The blocks add-on gives the pages of a site a kit to build landing pages. It works with every backend.

## What it adds

- **22 blocks** with the prefix `block-`: a section, columns, headings, texts, images, buttons, icon boxes, an accordion, a testimonial and more.
- **One theme** in `app.config.ts`: the colors and the fonts of the blocks.
- **Plain CSS** that works with or without Tailwind and Nuxt UI, in light and dark mode.
- **Block editor support**: the blocks are in the palette of the editor.

## Install

Install the package first, with the command at the top of this page. `extends` does not install it.

Then extend it. Pages must be on (`plutoPages.enabled`).

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  extends: ['@plutocms/core', '@plutocms/blocks'],
  plutoPages: {
    enabled: true,
  },
})
```

It needs `@plutocms/core` 0.72.0 or newer. The [WordPress import](/docs/start-here/coming-from-wordpress) writes pages made of these blocks.
