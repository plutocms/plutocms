The 3D add-on adds 3D models (`.glb`) to the media library of core. It works with every backend.

## What it adds

- **Upload**: the media library takes `.glb` files, up to 25 MB each.
- **A preview image**: at upload, the browser makes a still image of the model. A site shows it as the thumbnail, with no 3D code.
- **The viewer**: `Pluto3dViewer` shows the model in the admin and on your site. It turns with the mouse or a finger, and it can turn by itself.
- **A check**: a model that links files it does not hold (for example outside textures) gets a warning at upload.

three.js loads only in the browser, and only on the pages that show a model.

## Install

```bash [Terminal]
npm install @plutocms/3d
```

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  extends: [['@plutocms/supabase-shop', { install: true }], '@plutocms/3d']
})
```

Add it next to the backend layer of your app. It does not extend core itself, so core loads once.

```vue [ProductModel.vue]
<template>
  <Pluto3dViewer :media="model" auto-rotate />
</template>
```
