The shop add-on holds the parts of a shop that do not depend on the backend. It works with the Git CMS and with Supabase. The [Supabase shop](/layers/supabase-shop) brings it already.

## What it adds

- **The cart**: `useCart()`. Add, change the quantity, remove, and the subtotal. The browser keeps the cart, so it needs no database and works on a static site.
- **Current prices and stock**: after each page load, the cart reads its products again from the public API. A product that is gone or sold out leaves the cart.
- **Stock limits**: a visitor cannot add more units than the stock. A product made to order has no limit.
- **Price helpers**: `formatProductPrice` and the helpers that convert between cents and an amount.

## Install

Install the package first, with the command at the top of this page. `extends` does not install it.

Then extend it:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  extends: ['@plutocms/core', '@plutocms/shop']
})
```

Add it next to the backend layer of your app. It does not extend core itself, so core loads once.

```vue [AddToCart.vue]
<script setup lang="ts">
defineProps<{ product: PublicProduct }>()
const { add } = useCart<PublicProduct>()
</script>

<template>
  <UButton @click="add(product)">Add to cart</UButton>
</template>
```
