The SEO add-on makes a blog ready for search engines and social networks. It works with every backend.

## What it adds

- **SEO fields**: an SEO title, an SEO description, a social image and "Hide from search engines" on a post, with a preview of the search result and the social card in the admin.
- **Head tags**: the canonical URL, the `og:*` and `twitter:*` tags on each post page, with no page change.
- **A sitemap and robots.txt**: `/sitemap.xml` lists the published posts, `/robots.txt` keeps the admin out.
- **Author tags**: `<meta name="author">`, `article:author` and JSON-LD on a post page, and `<dc:creator>` in the feed.
- **An RSS feed**: `/feed.xml`, the newest posts.

## Install

Install the package first, with the command at the top of this page. `extends` does not install it.

Then extend it:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  extends: ['@plutocms/core', '@plutocms/seo']
})
```

Set the address of your site in `NUXT_PUBLIC_WEBSITE_URL`, so the sitemap and the feed have full URLs. On Supabase, use `@plutocms/supabase-blog` 0.20.0 or newer: it has the SEO columns. The author tags need `@plutocms/seo` 0.2.0 or newer.
