The Nuxt Content layer turns the Markdown pages of a Nuxt Content site into content of the Pluto admin. The pages stay Markdown files in your repository, and each save is a commit.

## What it adds

- **Content types from presets**: the `docs` preset makes a content type of a folder of pages.
- **The visual block editor**: edit the blocks of a page (MDC components) with forms, next to a live preview of the page.
- **A Markdown mode**: edit the source, with the same preview.
- **Hybrid rendering**: the pages are built with the site, and the server reads a page from the repository when it changed after the build.

This site uses it: we edit these pages in its admin.

## Install

```bash [Terminal]
npm install @plutocms/nuxt-content
```

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  extends: [['@plutocms/nuxt-content', { install: true }]],
  plutoNuxtContent: {
    types: [{ preset: 'docs', name: 'doc', source: '' }]
  }
})
```

The layer brings core and `@nuxt/content`. It needs Node 22.5 or newer.
