`@plutocms/blocks` is an add-on layer. It works with every backend (the Git CMS or Supabase). It gives:

- **22 blocks** for [pages](/docs/build/pages), with the prefix `block-`: `::block-section`, `::block-columns`, `::block-button`.
- **One theme** in `app.config.ts`. The colors and the fonts become CSS variables, on the server too.
- **Plain CSS with low specificity.** It works with or without Tailwind and Nuxt UI, in light and dark mode.
- **Accessible output.** A heading is a real `h1` to `h6`. A button with a link is an `<a>`. An accordion is made of `<details>`, so it needs no JavaScript. An image keeps its `alt`.

The blocks show in the palette of the [block editor](/docs/extend/edit-pages-visually). You can also write them as Markdown.

## Install

Install the package first. `extends` does not install it.

:pluto-install{name="@plutocms/blocks"}

Add it next to the backend layer of your app. It does not extend core itself: the app or its backend layer brings core. It needs `@plutocms/core` 0.72.0 or a newer version.

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  extends: ['@plutocms/core', '@plutocms/blocks'],
  plutoPages: {
    enabled: true,
  },
})
```

The layer adds its stylesheet to the app. Pages must be on, because the body of a page has the blocks field. See [Pages](/docs/build/pages). The route of your pages renders the body with `<PlutoBlocks :value="page.blocks" />`.

## A page example

A block has two colons. A block that holds other blocks has more colons than any block inside it. Put a blank line between sibling blocks.

```md [content/pages/home.md]
---
title: Home
status: published
layout: full
---

:::::block-section{bg="primary" color="#ffffff" padding="xl" align="center"}
::block-heading{level="1" size="3xl"}
Pages that load fast
::

::block-text{size="lg"}
Build a landing page with blocks, in the editor or in Markdown.
::

::block-button{label="Get started" link="/admin" align="center" size="lg"}
::
:::::

:::::block-section{padding="lg"}
::::block-columns{gap="lg"}
:::block-column{width="33.3"}
::block-icon-box{icon="i-lucide-zap" title="Fast" align="center"}
Pages load as plain HTML.
::
:::

:::block-column{width="33.3"}
::block-icon-box{icon="i-lucide-shield-check" title="Safe" align="center"}
Raw HTML that can run code is removed.
::
:::

:::block-column{width="33.3"}
::block-icon-box{icon="i-lucide-palette" title="Yours" align="center"}
Set the colors and the fonts in one place.
::
:::
::::
:::::
```

`layout: full` shows the blocks only, at full width. See [Pages](/docs/build/pages#the-layout-of-a-page).

## The blocks

The slot of a block is its default slot. A slot of **blocks** holds other blocks. An **inline** slot holds one line of text. A **rich** slot holds any Markdown.

| Block | Purpose | Main props | Slot |
| --- | --- | --- | --- |
| `block-section` | A band of the page. | `bg`, `image`, `overlay`, `color`, `padding`, `min-height`, `width`, `align`, `anchor` | Blocks |
| `block-columns` | A row of columns. | `gap`, `valign`, `wrap`, `stack` | `block-column` |
| `block-column` | One column. It can hold columns. | `width`, `padding`, `bg`, `radius`, `shadow`, `align`, `valign` | Blocks |
| `block-heading` | A heading, `h1` to `h6`. | `level`, `size`, `align`, `color` | Inline |
| `block-text` | A text. | `size`, `align`, `color` | Rich |
| `block-image` | An image with an optional caption. | `src`, `alt`, `caption`, `width`, `radius`, `align`, `link` | None |
| `block-button` | A button or a link. | `label`, `link`, `variant`, `size`, `align`, `full`, `color`, `icon` | None |
| `block-icon` | One icon. | `icon`, `size`, `color`, `align`, `label`, `link` | None |
| `block-divider` | A line. | `line`, `color`, `thickness`, `width`, `align`, `spacing` | None |
| `block-spacer` | Empty space. | `size` | None |
| `block-video` | A video from a page URL (YouTube or Vimeo). | `url`, `title`, `ratio`, `width`, `align` | None |
| `block-icon-list` | A list with icons. | `icon`, `color`, `gap`, `layout` | `block-icon-list-item` |
| `block-icon-list-item` | One item of an icon list. | `text`, `icon`, `link` | Inline |
| `block-icon-box` | An icon, a title and a text. | `icon`, `title`, `level`, `size`, `color`, `position`, `align`, `link` | Rich |
| `block-image-box` | An image, a title and a text. | `src`, `alt`, `title`, `level`, `position`, `radius`, `align`, `link` | Rich |
| `block-accordion` | A group of questions and answers. | `single` | `block-accordion-item` |
| `block-accordion-item` | One question. | `title`, `open` | Rich |
| `block-testimonial` | A quote with a name. | `name`, `role`, `image`, `align` | Rich |
| `block-counter` | A big number with a caption. | `value`, `prefix`, `suffix`, `title`, `color`, `align` | None |
| `block-social-icons` | A row of icon links. | `shape`, `size`, `gap`, `color`, `align` | `block-social-link` |
| `block-social-link` | One social link. | `network`, `url`, `label`, `icon` | None |
| `block-gallery` | A grid of images. | `columns`, `gap`, `ratio` | `block-image` |

A prop that the kit does not know is ignored. The block shows its default.

::note
A `block-image` with no `alt` renders `alt=""`. Give each image a text alternative.
::

## Theme

Set the theme in the `app.config.ts` of your app. Restart the dev server after a change.

```ts [app/app.config.ts]
export default defineAppConfig({
  plutoBlocksTheme: {
    colors: {
      primary: '#0f766e',
      secondary: '#64748b',
      text: '#1c1917',
      accent: '#d97706',
      muted: '#78716c',
      surface: '#f5f5f4',
      background: '#fffdf8',
      onPrimary: '#ffffff',
    },
    fonts: {
      heading: '"Fredoka", sans-serif',
      body: 'system-ui, sans-serif',
    },
  },
})
```

Every key is optional. The layer writes the theme as one `:root` rule in the head of the page, on the server too, so the first paint has the colors. A name that the layer does not know, and a value that is not a safe CSS color or font stack, is dropped.

| Key | Variable | Default |
| --- | --- | --- |
| `colors.primary` | `--pluto-blocks-color-primary` | `--ui-primary` of Nuxt UI, else `#4f46e5` |
| `colors.secondary` | `--pluto-blocks-color-secondary` | `--ui-secondary`, else `#64748b` |
| `colors.accent` | `--pluto-blocks-color-accent` | `--ui-warning`, else `#d97706` |
| `colors.text` | `--pluto-blocks-color-text` | The color of the page |
| `colors.muted` | `--pluto-blocks-color-muted` | A softer mix of the text color |
| `colors.surface` | `--pluto-blocks-color-surface` | `--ui-bg-elevated`, else a light mix of the text color |
| `colors.background` | `--pluto-blocks-color-background` | Transparent |
| `colors.onPrimary` | `--pluto-blocks-color-on-primary` | `--ui-bg`, else `#fff` |
| `fonts.heading` | `--pluto-blocks-font-heading` | The font of the page |
| `fonts.body` | `--pluto-blocks-font-body` | The font of the page |

On a site with Nuxt UI, the defaults follow its colors and its light and dark mode. On a site without it, they follow the color of the page.

::note
A color that you set is the same in light and dark mode. Choose a color that works in both, or set the variables under `.dark` in the CSS of your site.
::

You can also set the variables in your own CSS. The kit has more variables for the scale: `--pluto-blocks-space-{xs,sm,md,lg,xl,2xl}`, `--pluto-blocks-radius-{sm,md,lg,xl,full}` and `--pluto-blocks-container` (`72rem`).

## Values

- **Spacing, gaps and sizes** take a step of the scale or a CSS length. The scale is `none`, `xs`, `sm`, `md`, `lg`, `xl` and `2xl` (from `0.5rem` for `xs` to `8rem` for `2xl`). A length is `24px`, `3rem` or `60vh`. A bare number is pixels.
- **A color prop** (`bg`, `color`, `overlay`) takes a token or a CSS color. The tokens are `primary`, `secondary`, `text`, `accent`, `muted`, `surface` and `background`. A CSS color is `#0f766e` or `rgb(0 0 0 / 50%)`.
- **A link** is a path (`/pricing`), an anchor (`#faq`), or an `http`, `https`, `mailto` or `tel` URL. The block ignores any other link.

## Columns on small screens

Columns stack on a small screen. Set `stack` on `block-columns`:

| `stack` | Columns stack below |
| --- | --- |
| `md` (default) | 768 px |
| `sm` | 640 px |
| `never` | They never stack. |

## Edit the blocks in the admin

The blocks are in the palette of the block editor, with a panel for each block. Add them with the **Add** button, and set their props in the block panel. See [Edit pages visually](/docs/extend/edit-pages-visually).

## Style the blocks

The CSS is in the `components` cascade layer. Each selector is one class, such as `.pluto-blocks-button`, so your own CSS and any Tailwind utility wins. The values of the props are `data-*` attributes, such as `data-variant="outline"`.

## Limits

- The kit has no values for each breakpoint. Only `stack` of the columns changes with the screen.
- The kit has no dark color for each theme color.
- The counter does not animate. The kit has no carousel, no tabs and no form.
