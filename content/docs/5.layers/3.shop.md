`@plutocms/shop` is the shop add-on: the parts of a shop that do not depend on the backend, for the Git CMS and for Supabase. A shop layer of a backend builds on it. Today it gives:

- **The cart:** `useCart()`. The browser keeps the cart (localStorage). It needs no database and no server route, so it works on a static site too.
- **The price helpers:** `formatProductPrice(cents)` and the helpers that convert between cents and an amount.

The [Supabase shop](/docs/layers/supabase-shop) extends this layer, so a Supabase shop has these already.

## Install

Install the package first. `extends` does not install it.

:pluto-install{name="@plutocms/shop"}

Add it next to the backend layer of your app. It does not extend core itself: the app or its backend layer brings core, so core loads once.

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  extends: ['@plutocms/core', '@plutocms/shop']
})
```

## Use the cart

```vue
<script setup lang="ts">
const props = defineProps<{ product: PublicProduct }>()
const { add, count, ready, quantityOf, limitOf } = useCart<PublicProduct>()

const full = computed(() => quantityOf(props.product.id) >= limitOf(props.product))
</script>

<template>
  <UButton :disabled="full" @click="add(product)">Add to cart</UButton>

  <NuxtLink to="/cart">Cart ({{ ready ? count : 0 }})</NuxtLink>
</template>
```

| Name | What it does |
| --- | --- |
| `add(product, quantity?)` | Adds units (default 1), up to the limit. It returns the units that it added. |
| `setQuantity(id, quantity)` | Sets the units, up to the limit. `0` removes the product. |
| `remove(id)`, `clear()` | Removes one product, or all of them. |
| `lines` | The products in the cart: `id`, `quantity`, `product`, `subtotal` (cents) and `limit`. |
| `count`, `subtotal` | The units of all products, and their price in cents. |
| `isEmpty`, `has(id)`, `quantityOf(id)` | The state of the cart. |
| `limitOf(product)` | The most units of a product that the cart takes. `0` means sold out. |
| `ready` | True in the browser after the cart loads. |
| `refresh()` | Reads the products again from the public API. |

A product needs `id` and `price` (in cents). The cart keeps a copy of each product, so the cart page shows at once.

### Show the count after the cart loads

The server does not know the cart of a visitor. On the server, and until the page is ready in the browser, the cart is empty and `ready` is false. Show the count only when `ready` is true. Then the page does not show a wrong number for a moment.

### Current prices and stock

After each page load, the cart reads its products again from the [Public API](/docs/build/public-api). A static site reads the public index. Thus:

- A new price replaces the old price.
- A quantity above the new stock goes down to the stock.
- A product that the API no longer has, or a product with no stock, leaves the cart.
- When the API does not answer, the cart does not change.

`refresh()` returns the lines that it removed and the lines that it changed. A cart page can tell the visitor.

::warning
The cart is in the browser, so a visitor can change it. A checkout must calculate the price again on the server.
::

## Settings

Change the settings in the `app.config.ts` of your app:

```ts [app/app.config.ts]
export default defineAppConfig({
  plutoShop: {
    cart: {
      type: 'product',
      storageKey: 'pluto-cart',
      maxQuantity: 99,
      stockField: 'stock',
      madeToOrderField: 'madeToOrder',
    },
  },
})
```

| Setting | Default | Meaning |
| --- | --- | --- |
| `type` | `'product'` | The public content type of the products. |
| `storageKey` | `'pluto-cart'` | The localStorage key. A site under a sub path adds the path, so two sites on one domain keep two carts. |
| `maxQuantity` | `99` | The most units of one product. |
| `stockField` | `''` | A number field with the units in stock. Empty: no stock limit. |
| `madeToOrderField` | `''` | A boolean field. When it is true, the product has no stock limit. |

A product with no number in the stock field has no stock limit. The Supabase shop sets `stockField: 'stock_quantity'` and `madeToOrderField: 'is_custom'`.

## Prices

Prices are integer cents. `4990` means R$ 49,90. Do not divide by 100 in your app. Use the auto-imported helpers:

- `formatProductPrice(cents, options?)` formats cents as a currency string. The currency is BRL by default. For another currency: `formatProductPrice(cents, { currency: 'USD' })`.
- `centsToAmount(cents)` converts cents to an amount (`4990` to `49.9`).
- `amountToCents(amount)` converts an amount to cents, with rounding (`49.9` to `4990`).
- `digitsToCents(text)` reads the digits of a price input as cents (`R$ 50,90` to `5090`).
- `formatCurrency(amount, options?)` formats an amount, not cents.
