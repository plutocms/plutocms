This page has one section for each release with a breaking change, the newest first. Each section names the package and the version, tells you what changed, and gives the steps for your app.

Before you update:

1. Find the version of each `@plutocms` package that your app uses now.
2. Read each section between that version and the new one.
3. Do the steps of each section, then update the packages together.

Pluto is in **alpha**. An alpha release can have a breaking change with no section here. From the beta on, every breaking change gets a section. See [Versions and support](/docs/reference/versions).
