This page uses the default setup of Pluto: the blog template with the Git CMS. Your posts are Markdown files in the project, and each save is a Git commit. You need no account, no database, and no settings.

You need [Node.js](https://nodejs.org/) 22 or newer.

::steps{level="2"}

## Create the project

Run this command in a terminal:

::code-group{sync="package-manager"}
```bash [npm]
npm create pluto@latest
```

```bash [pnpm]
pnpm create pluto@latest
```

```bash [yarn]
yarn create pluto
```

```bash [bun]
bun create pluto@latest
```
::

The CLI asks some questions. Press **Enter** at each question to keep the default. The defaults are the Git CMS and the blog template. The CLI then downloads the template and installs the dependencies.

::tip
To see the templates before you start, open the [templates store](/templates). Each template has a live demo.
::

::pluto-figure{src="/media/2026/11/create-pluto-finish-nkw2i.png" alt="The terminal after create-pluto, with the next steps" caption="The terminal at the end of create-pluto, with the Next steps box" :width='1213' :height='714'}
::

## Start the dev server

Go into the project folder and start the dev server:

::code-group{sync="package-manager"}
```bash [npm]
cd my-pluto-project
npm run dev
```

```bash [pnpm]
cd my-pluto-project
pnpm run dev
```

```bash [yarn]
cd my-pluto-project
yarn dev
```

```bash [bun]
cd my-pluto-project
bun run dev
```
::

Open `http://localhost:3000`. The blog shows one sample post, **Hello, world**.

## Open the admin

Open `http://localhost:3000/admin`. On your machine, you do not sign in: the dev server signs you in as a **Local** user. The dashboard shows your posts.

::pluto-figure{src="/media/2026/11/admin-home-default-blz02.png" alt="The Pluto admin dashboard of a new blog" caption="The admin dashboard of a new blog, signed in as Local" :width='1440' :height='851'}
::

## Write a post

Select **New Post**. Type a title, and write the text in the editor. Then select **Publish**.

::pluto-figure{src="/media/2026/11/admin-new-blog-post-yclb0.png" alt="The post editor with a title and some text" caption="The New Post editor with a title, some text, and the Publish button" :width='1440' :height='851'}
::

Pluto writes the post to `content/posts/<slug>.md` and makes a Git commit in your project. Select **Save draft** in place of **Publish** to keep a post off the site.

## See it on the site

Select **View site** in the admin bar. Your post is on the home page. While you are signed in, the admin bar shows on the site too, with **Edit Post** on a post page.

::pluto-figure{src="/media/2026/11/quickstart-site-z1raz.png" alt="The blog home page with the new post" caption="The blog home page with the new post and the admin bar at the top" :width='1440' :height='851'}
::

::

## What you have now

- A Nuxt app with the blog pages in `app/pages/`. Change them as you like. See [Project structure](/docs/build/project-structure).
- The admin at `/admin`, with posts, media, and settings.
- The posts in `content/posts/`, in your Git history.
- Tags, categories and authors, each with its pages. See [Tags and categories](/docs/build/tags-and-categories) and [Authors](/docs/build/authors).
- The [SEO add-on](/docs/layers/seo): SEO fields, `sitemap.xml`, `robots.txt` and `feed.xml`.

The local sign-in and the local commits work in development only. To edit the posts on a live site, deploy it and connect GitHub. Pluto does the setup for you.
