A Pluto project is a Nuxt app. It extends one or more layers.

## The core blog template

The `core-blog` template has no database. It has these files:

```text
.
├─ app/
│  ├─ assets/css/tailwind.css
│  ├─ layouts/default.vue
│  ├─ pages/
│  │  ├─ index.vue
│  │  └─ posts/[slug].vue
│  └─ app.vue
├─ content/
│  └─ posts/
│     ├─ hello-world.md
│     └─ pluto-works-out-of-the-box.md
├─ .env.example
├─ nuxt.config.ts
└─ package.json
```

- `content/posts/` holds the posts as Markdown files.
- `app/pages/` holds the public pages. They read posts with `usePlutoCmsList` and `usePlutoCmsItem`.
- `nuxt.config.ts` extends `@plutocms/pluto` and sets the `plutoCms` options.

## The Supabase templates

The `supabase-blog` and `supabase-shop` templates have these folders:

- `app/` with `app.vue`, a layout, a `Navbar.vue` component, and the public pages.
- `app/assets/css/tailwind.css`, the CSS entry of the app.
- `shared/types/supabase.ts`, the generated database types.
- `public/`, with a favicon and `robots.txt`.

The blog template also has `i18n/locales/` with a JSON file for each language of the public site.

## `app.vue`

`app.vue` wraps the app in `PlutoRoot`.

```vue [app/app.vue]
<template>
  <PlutoRoot>
    <NuxtPage />
  </PlutoRoot>
</template>
```

`PlutoRoot` includes the admin navbar, `NuxtLayout`, `NuxtLoadingIndicator`, and the base styles.

## `nuxt.config.ts`

The config extends the layer for the template. This example shows the core blog template:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  extends: [['@plutocms/pluto', { install: true }]],
  css: ['~/assets/css/tailwind.css'],
  plutoCms: {
    enabled: true,
    storage: 'fs',
    github: { repo: 'owner/name', branch: 'main', appSlug: 'my-blog-cms' },
    dir: 'content'
  }
})
```

The real template reads the repository and the app slug from environment variables. It also picks the storage by environment. See [GitHub CMS setup](/github-cms/setup).

## The CSS entry

The app owns the only Tailwind build. The CSS entry starts with three imports:

```css [app/assets/css/tailwind.css]
@import 'tailwindcss';
@import '@nuxt/ui';
@import '#build/pluto.css';
```

Add your own `@theme` after these lines. See [Styles](/core/styles).

## The admin routes

Core owns the `/admin` routes. They need no page files in your app.

| Route | Purpose |
| --- | --- |
| `/admin` | Redirects to `/admin/home` |
| `/admin/home` | The dashboard |
| `/admin/login` | The sign-in page |
| `/admin/settings` | The settings pages |
| `/admin/content/<type>` | The generated list, new, and edit pages of a content type |
